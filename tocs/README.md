# Character Encoding Names and Identifiers

This directory contains indices of names and identifiers for character encodings from other systems.

* `IANA.txt` - Maps names and `MIBenum` constants from the IANA charset registry to the identifiers used in this repository.

* `CFStringEncoding.txt` - Maps `CFStringEncoding` constants from Apple's Core Foundation framework to the identifiers used in this repository.

* `NSStringEncoding.txt` - Maps `NSStringEncoding` constants from NeXT and Apple's Foundation framework to the identifiers used in this repository.

* `DisplayNames.txt` - Provides the names and categories used at https://www.kreativekorp.com/charset/encoding/. May also be used by other vendors to provide human-readable names for character encodings.

* `KTEFiles.txt` and `OldNames.txt` - Names and identifiers used by older iterations of https://www.kreativekorp.com/charset/encoding/, maintained for compatibility.
