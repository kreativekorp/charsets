# Legacy Computing Character Encoding Test Cases

This directory contains test cases for character encodings originating from legacy computers.

These text files use the same format as the text files in the `tables` directory. See the `README.md` file in that directory for details.

The file name (without the .txt extension) is used as the identifier for the encoding under test.

The `tablint.py` tool with the `-t` option will check these files for syntax and duplicate mappings, but will not actually perform the tests.
